# 2026-09-14 -- Mediated content pool semantic clarity research item

**Completed:**
- `Research/completed/2026-08-20-mediated-content-pool-semantic-clarity.md` -- answers the research question "what domain-independent knowledge-engineering methods improve semantic clarity, conflict-surfaceability, and explicit resolvability in a mediated content pool?" Core finding: pool-level conflict-detection methods (semantic normalisation, ontology alignment with built-in reasoning, Description Logic (DL) justification-finding, Shapes Constraint Language (SHACL) structural validation) must be paired with resolvability-annotation methods (provenance chains, statement-level RDF-star annotation, minimal-axiom-set justifications) rather than either layer adopted alone. The Minimal Axiom set (MinA) mechanism is identified as the strongest single transferable mechanism because it simultaneously detects a conflict's minimal cause and produces the resolvability structure a resolver needs.

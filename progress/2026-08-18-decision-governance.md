1. **Did the process work?** Yes. First, the first review-workflow commit raced with a `docs: rebuild site` commit landing on `main` and was rejected, so that pass's violations had to be tracked and fixed without the `review_count` frontmatter having incremented -- this matches an already-documented Known Recurring Pattern (`research-review.yml`'s own commit-and-push step races with a concurrent commit). This is a variant of a documented pattern (unlabeled §5 paragraph openers) but the specific mechanism, a well-intentioned fix for one violation (2c self-citation) introducing a different violation (missing label), is new.

Treat "remove a bad citation" and "the sentence still needs a label" as two separate, both-mandatory sub-steps.
4. **Is this a pattern?** Partially. The `research-review.yml` commit race is already a documented pattern in `.github/copilot-instructions.md` (confirmed it in practice this session).
